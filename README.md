مشاريع ومحتوى عربي: لمعالجة اللغة العربية، دعم الاتجاه من اليمين لليسار (RTL)، والتعلّم بالعربي.

#### Arabic NLP & AI

* [aub-mind/arabert](https://github.com/aub-mind/arabert) - Pre-trained Transformers for Arabic (AraBERT, AraGPT2, AraELECTRA).
* [CAMeL-Lab/camel_tools](https://github.com/CAMeL-Lab/camel_tools) - Arabic NLP toolkit from NYU Abu Dhabi: morphology, dialect ID, NER, sentiment.
* [bakrianoo/aravec](https://github.com/bakrianoo/aravec) - Pre-trained Arabic word embeddings.
* [ARBML/ARBML](https://github.com/ARBML/ARBML) - Many Arabic NLP and computer vision projects with web, CLI and notebook demos.
* [ARBML/klaam](https://github.com/ARBML/klaam) - Arabic speech recognition, classification and text-to-speech.
* [linuxscout/mishkal](https://github.com/linuxscout/mishkal) - Automatic Arabic text vocalization (Tashkeel).
* [HusseinYoussef/Arabic-OCR](https://github.com/HusseinYoussef/Arabic-OCR) - OCR system for typed Arabic text.
* [Alfanous-team/alfanous](https://github.com/Alfanous-team/alfanous) - Arabic search engine API for the Quran.

#### Arabic for Developers (RTL, Fonts, Text)

* [khaled-alshamaa/ar-php](https://github.com/khaled-alshamaa/ar-php) - Arabic search, presentation and processing for PHP websites.
* [mpcabd/python-arabic-reshaper](https://github.com/mpcabd/python-arabic-reshaper) - Reshape Arabic text for apps that don't support it.
* [pnarimani/RTLTMPro](https://github.com/pnarimani/RTLTMPro) - Right-to-left Arabic and Persian support for Unity TextMeshPro.
* [rastikerdar/vazirmatn](https://github.com/rastikerdar/vazirmatn) - Open-source Persian/Arabic font.
* [aliftype/amiri](https://github.com/aliftype/amiri) - Amiri (أميري), a classic Naskh typeface.

#### Learn in Arabic

* [mostafa-saad/ArabicCompetitiveProgramming](https://github.com/mostafa-saad/ArabicCompetitiveProgramming) - Material for an Arabic video series on algorithms and competitive programming.
* [Python in Arabic](https://www.facebook.com/groups/132453040237101) - Learn Python in Arabic.
